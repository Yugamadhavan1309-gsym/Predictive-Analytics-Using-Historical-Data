# 📈 Predictive Analytics Using Historical Data

## 📌 Project Overview

This project focuses on predicting Walmart weekly sales using historical sales data. The workflow includes data preprocessing, exploratory data analysis (EDA), feature engineering, machine learning model development, and performance evaluation using Linear Regression.

---

## 🎯 Objective

To build a predictive analytics model that forecasts Walmart weekly sales using historical data and evaluate its performance.

---

## 📂 Dataset

This project uses the Walmart Sales Forecasting dataset.

Dataset Files:
- train.csv
- test.csv
- features.csv
- stores.csv

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## 📊 Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Understanding
4. Data Cleaning
5. Exploratory Data Analysis (EDA)
6. Feature Engineering
7. Feature Scaling
8. Train-Test Split
9. Build Linear Regression Model
10. Model Evaluation
11. Sales Prediction
